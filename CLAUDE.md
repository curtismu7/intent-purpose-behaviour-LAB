# intent-purpose-behaviour-LAB

Demo-tier standalone app: Ping "Intent, Purpose and Behaviour" release claims (deck slide 48, release 2026-11-02), plus on-behalf-of and ID-JAG. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7100). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7100 docker compose up --build -d`. Node 26 only.
- Settings: the one shared file `~/Development/.env` (or `STANDALONE_ENV`), optional; this app's key is `IPB_LAB_MODE` (never a bare `MODE`). The doctor reports the file's presence and mode, never values.
- UI: `web/src/styles/standalone-ui.css` is vendored byte-for-byte from the shared standard (never edit it); app CSS is `web/src/app.css`, tokens only (no colour literals, no `prefers-color-scheme`, no `!important`, breakpoints 600/900). Check: `bash ~/Development/AI-DEMO-Standalone/scripts/check-drift.sh .`.
- Modes: **Mock** = pure tables (`server/src/mockTable.json`, generated by `npm run mock-table` from the live engine; a test fails on drift). **Live** = real engine: real RS256 (RSA keygen only, never EC), real verification, real baseline learning. Both loopback-only, zero outbound (netguard + a test).
- Core: `server/src/{call,intent,purpose,behaviour,policy,decide,engine,evaluation}.js` (signals), `{jwt,keys,oauth}.js` (token flows), `data.js` (story, `{{cast}}` tokens, 3 verticals in `cast.js`), `app.js` (API). Diagrams: `server/diagrams/*.json` (diagram-studio/1, loaded by name).
- Masking (`server/src/mask.js`, a heuristic): everything typed goes through `call.js` -> `cleanInput` (controls DELETED, NFKC, 3 percent rounds, keyword/userinfo/JSON/token detectors); evaluate and baseline answers go through `maskDeep` again; error texts are fixed (never repeat input); over-long values are refused whole; credential-shaped tool/arg names and workspace ids are refused (400). Unknown paths JSON 404, wrong method 405 + Allow, shell only for dot-free paths. A new endpoint or field must be added to the matrix in `server/test/leak.test.js`.
- Rules that bite: only the deterministic tier may deny (policy validation rejects a scored signal that can; `decide` asserts it); a new agent is never enforced (phases learning, scoring, enforcing); refused or held calls are not learned; loopback bind, same-origin writes; only `.example`/`.invalid` hosts; no regex from user input; ports 7100-7149; the gateway app is always called "P1 Privilege Agent App"; tokens are mock-issued and shown raw; no client secrets anywhere.
- Field names (AIIntent, PurposeProfile, BehaviourConfig, OBO/Redeem) come from the console swagger of 2026-10-31, schema only. Runtime behaviour is UNVERIFIED. Anything else (reason codes, scoring points, thresholds, pattern syntax, similarity stand-in) is lab-invented and tagged so.
- Sibling: `id-jag-standalone-LAB` (text mention only, never import).
- SE k8s build deferred (owner, 2026-10-31); no k8s manifests. No catalog id yet.
