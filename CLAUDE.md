# intent-purpose-behaviour-LAB

Demo-tier standalone app: Ping "Intent, Purpose and Behaviour" release claims (deck slide 48, release 2026-11-02), plus on-behalf-of and ID-JAG. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7100). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7100 docker compose up --build -d`. Node 26 only.
- Settings: the one shared file `~/Development/.env` (or `STANDALONE_ENV`), optional; this app's key is `IPB_LAB_MODE` (never a bare `MODE`). The doctor reports the file's presence and mode, never values.
- UI: `web/src/styles/standalone-ui.css` is vendored byte-for-byte from the shared standard (never edit it); app CSS is `web/src/app.css`, tokens only (no colour literals, no `prefers-color-scheme`, no `!important`, breakpoints 600/900). Check: `bash ~/Development/AI-DEMO-Standalone/scripts/check-drift.sh .`.
- Modes: **Mock** = pure tables (`server/src/mockTable.json`, generated by `npm run mock-table` from the live engine; a test fails on drift). **Live** = real engine: real RS256 (RSA keygen only, never EC), real verification, real baseline learning. Both loopback-only, zero outbound (netguard + a test).
- Core: `server/src/{call,intent,purpose,behaviour,policy,decide,engine,evaluation}.js` (signals), `{jwt,keys,oauth}.js` (token flows), `data.js` (story, `{{cast}}` tokens, 3 verticals in `cast.js`), `app.js` (API). Diagrams: `server/diagrams/*.json` (diagram-studio/1, loaded by name).
- Masking: `server/src/shared/{mask,hygiene}.js` are copied unchanged from shared-masker 9bc664a (1.4.0; never edit, re-copy). `server/src/mask.js` is the thin adapter (`cleanInput`, `looksLikeCredential(Name)`, `maskResponseText`, `maskDeep`, `maskFlow`) plus five rules of ours (`TYPED_EXTRAS`) for gaps in the shared masker; heuristic. Typed text goes through `call.js` -> `cleanInput`; EVERY `res.json` goes through `maskDeep` (app.js), except the two token flows (`maskFlow`: tokens and hop panes are opaque, shown raw by design); the workspace store masks at write time. The edge follows the shared Express recipe (route table -> 405 + Allow, 415 for a non-utf-8 charset, 400 for a malformed escape, page shell only for `isPageAddress` paths, JSON 404, catch-all error handler with fixed codes, `bad_workspace` before any slot). Error texts are fixed (never repeat input); over-long values are refused whole. A new endpoint goes in the `ROUTES` table and in `server/test/sweep.js`; a new field in the places there.
- Rules that bite: only the deterministic tier may deny (policy validation rejects a scored signal that can; `decide` asserts it); a new agent is never enforced (phases learning, scoring, enforcing); refused or held calls are not learned; loopback bind, same-origin writes; only `.example`/`.invalid` hosts; no regex from user input; ports 7100-7149; the gateway app is always called "P1 Privilege Agent App"; tokens are mock-issued and shown raw; no client secrets anywhere.
- Field names (AIIntent, PurposeProfile, BehaviourConfig, OBO/Redeem) come from the console swagger of 2026-10-31, schema only. Runtime behaviour is UNVERIFIED. Anything else (reason codes, scoring points, thresholds, pattern syntax, similarity stand-in) is lab-invented and tagged so.
- Intent catalogue and customer intent (tabs "Intent catalogue" and "Customer intent"): `server/src/builtinIntents.json` is the sanitised snapshot of the local Privilege console's `GET /v1/aiintents?ObjectMeta.Namespace=procyon` (measured 2026-11-18; 25 built-ins, 12 Acting; full copy in `docs/console-aiintents-snapshot-2026-11-18.json`). `server/src/consoleIntents.js` compiles the console's REAL regex patterns (not the story tab's invented mini-syntax) behind a catastrophic-backtracking guard (`backtrackingRisk`, compile-time — JS regexes are synchronous, so a wall-clock guard alone cannot save you; the console's own 53 patterns all pass the guard). `server/src/intentCatalogue.js` serves the catalogue + simulator + customer intents (per-workspace via `workspaces.intents`); a custom intent with a built-in's name REPLACES it (console clone rule). `server/src/consoleSource.js` is the owner-run Real source: the local console only, loopback-host check, key/secret as `x-api-key`/`x-api-secret` headers, never in a URL, never logged. Tests: `server/test/consoleIntents.test.js`, `server/test/intentRoutes.test.js`, `web/src/App.intents.test.jsx`.
- "What Privilege did" (rule 25): `web/src/gateway-trace/{GatewayTrace.jsx,gateway-trace.css,gateway-trace.test.jsx}` and `server/src/gatewayTrace.js` are vendored byte-for-byte from `AI-DEMO-Standalone/shared/gateway-trace/` and pinned by `web/src/gateway-trace/gateway-trace.sha256` (`scripts/gateway-trace.test.mjs` fails on an edited copy; re-vendor, never edit). `server/src/gatewayExchanges.js` builds the traces: `/api/evaluate` (the lab's own simulated gateway, Mock and Live alike, source `mock`, every decision `checked` and in `decide()`'s order; a held, alerted or unscored signal is `info`, never a pass) and `/api/privilege-check` (the real AI Guard hop: only `inferred` or `observed`, never `checked`; no bearer, no query string). The token flows (obo, idjag) are not traced: no decision there is the gateway's. Real mode against the live gateway has not been run.
- Sibling: `id-jag-standalone-LAB` (text mention only, never import).
- SE k8s build deferred (owner, 2026-10-31); no k8s manifests. No catalog id yet.
- Run observability (rule 27): `web/src/run-observability/` and `server/src/runObservability.js` are vendored byte-for-byte from `AI-DEMO-Standalone/shared/run-observability/` and pinned (`scripts/run-observability.pin.test.mjs`). This lab reads no logs, so it has no readers file and no `RUN_OBS_*` name. Its rows come from `server/src/runRecord.js`: Mock and Live evaluate and OBO runs (Live rows are the in-process engine's simulated rows, stored with source `mock`; Real privilege-check and the ID-JAG flow are not recorded yet). One stdout line per policy-point decision. The one exemption in the `RUN_OBS_` scan is the vendored core, matched by exact path (`scripts/run-observability.pin.test.mjs`).
